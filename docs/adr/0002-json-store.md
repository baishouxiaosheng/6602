# ADR 0002 · 用带版本的 JSON 文件做数据存储

- 状态：已采纳
- 决定：`storage/json_store.py`，一条记录一个文件，信封带 `schema_version` / `revision`，原子写入，历史版本另存。
- 理由：单机单用户、约 300 条目录记录；文件可直接打开查看，天然适合作为课程要求的“可观察证据”；零运维。
- 备选：SQLite（并发与查询更好，但证据不直观）——保留为扩展，接口 `JsonStore` 的方法集足以无痛替换。
- 影响：不支持多进程并发写；`list_games` 每次读全部文件（300 款下可接受，必要时在 `StoreCatalog` 加内存缓存）。
