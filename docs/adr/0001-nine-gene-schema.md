# ADR 0001 · 九维基因结构与 0–4 等级

- 状态：已采纳（待组内确认后冻结）
- 背景：需要一组既能表达“为什么喜欢”，又能被商店文本和评测原句佐证的维度。
- 决定：采用 `docs/02-gene-schema.md` 的九个维度，等级 0–4 整数，未知用 `null`。骨架来自 Quantic Foundry 动机模型，MDA 交叉核对。
- 备选：直接用 Steam 标签（无法发现跨类型相似）；文本嵌入向量（不可解释、无法逐维给证据）；连续 0–1 分值（模型标注不稳定，难写锚点）。
- 影响：修改维度或锚点使全部标注失效；`GENE_SCHEMA_VERSION` 记录在每条标注上。
