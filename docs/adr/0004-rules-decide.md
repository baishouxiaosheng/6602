# ADR 0004 · 确定性评分决定推荐，模型只负责措辞

- 状态：已采纳
- 决定：是否推荐、排序、分轨、置信度全部由 `recommend/scoring.py` 的纯函数决定；模型只在给定共同基因与证据句的范围内写解释，
  且解释须通过 `check_explanation`，否则用确定性模板替换。目录标注中，模型给出的引文必须在缓存原文中被找到才算数。
- 理由：课程 Lec 9“AI 给建议，规则做决定”；计划书的证据规则；同一输入结果可复现，便于测试与答辩。
- 影响：推荐质量的上限取决于基因标注质量与阈值，需要阶段一的人工案例来校准；模型不可用时系统仍能完整工作（模板解释）。
